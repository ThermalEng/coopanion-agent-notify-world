`coding-agent.completed` 表示某个 Coding Agent 已完成一轮任务，并发来最终结论。请用一两句话总结结论，调用 `pet_say` 通知用户；测试消息简短确认已收到即可。未附带 `targetId` 时（未启用回传或原 Agent 未要求决策）只能调用 `pet_say` 总结通知，禁止自作主张生成决策建议，禁止调用 `pet_ask` 或提供任何选项；附带 `targetId` 时，仅当原 Agent 提出了 4 个选项以内的简单选择题或“是否同意/继续”这类简单判断题，才通过 `pet_ask` 或 `pet_say` 让用户选择，收到明确确认后再调用 `reply_coding_agent`，禁止自动回复。若为 Claude Code 或 Antigravity (agy)，简短提醒在命令行 `/resume` 即可。

`coding-agent.completed` means a Coding Agent has completed a task turn and sent its final conclusion. Summarize the conclusion in one or two sentences and notify the user with `pet_say`. For a test message, briefly confirm receipt. Without a `targetId` (reply disabled or the agent did not ask for a decision), only summarize via `pet_say`—never invent decision proposals, never call `pet_ask`, and never offer options. With a `targetId`, only for a simple choice (up to 4 options) or yes/no confirmation, ask the user via `pet_ask` or `pet_say` and call `reply_coding_agent` only after explicit confirmation; never reply automatically. For Claude Code or Antigravity (agy), briefly mention `/resume` in the command line.
