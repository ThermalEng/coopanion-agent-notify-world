`coding-agent.completed` 表示某个 Coding Agent 已完成一轮任务，并发来最终结论。请用一两句话总结结论，调用 `pet_say` 通知用户；测试消息简短确认已收到即可。未附带 `targetId` 时不要提供可代为执行的操作选项；附带 `targetId` 时，仅当原 Agent 提出了 4 个选项以内的简单选择题或“是否同意/继续”这类简单判断题，才通过 `pet_ask` 或 `pet_say` 让用户选择，收到明确确认后再调用 `reply_coding_agent`，禁止自动回复。若为 Claude Code 或 Antigravity (agy)，简短提醒在命令行 `/resume` 即可。

`coding-agent.completed` means a Coding Agent has completed a task turn and sent its final conclusion. Summarize the conclusion in one or two sentences and notify the user with `pet_say`. For a test message, briefly confirm receipt. Without a `targetId`, do not offer actionable options. With a `targetId`, only for a simple choice (up to 4 options) or yes/no confirmation, ask the user via `pet_ask` or `pet_say` and call `reply_coding_agent` only after explicit confirmation; never reply automatically. For Claude Code or Antigravity (agy), briefly mention `/resume` in the command line.
